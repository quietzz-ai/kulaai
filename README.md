## FAQ

**Q1：KULAAI 和官方平台输出质量有区别吗？**

正规聚合平台走官方 API 原生调用，输出质量与官网一致。需要注意区分做了二次限制的平台，实际可用 token 会缩水。

**Q2：使用聚合平台安全吗？对话数据会被保存吗？**

正规平台会明确说明隐私政策，对话内容可能被匿名化用于改善服务，但不会关联到个人身份。敏感信息建议避免输入。

**Q3：免费额度用完后怎么办？**

大多数平台采用"免费额度 + 付费升级"模式。免费额度通常满足日常学习和轻度使用。用完后可订阅价格合理的付费套餐，或通过邀请好友、每日签到获取额外额度。

**Q4：哪个模型最适合我？**

- 写代码 → ChatGPT
- 长文档分析、论文精读 → Claude
- 看图、视频分析 → Gemini
- 查热点资讯 → Grok

**Q5：长上下文能力如何？**

Claude 支持 20 万 token 上下文窗口，Gemini 支持 100 万 token，原生调用无二次截断，信息遗漏率低至 5%。

**Q6：适合极客型深度用户吗？**

如果你需要完全定制的 API 调用和深度工程集成，官方直连可能更适合。KULAAI 更适合不想折腾、追求效率的普通用户和职场人。
